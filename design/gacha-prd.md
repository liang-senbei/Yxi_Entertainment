# PRD · 抽卡动画「擦星星」（2026-09-06 设定，2026-09-07 大改一次）

## 老板给了什么

- **九宫格**（`design/gacha/抽卡九宫格.png`）：整条流程。抱着**暗色星星**睡着 → **金色光环 + 光柱蓄力** →
  心变成对应品质的颜色、表情跟着变 → 回到平静。
- **六张状态图**：初始阶段（灰星星）/ 擦拭过程中 / 出蓝 / 出紫 / 出红 / 出金。
  表情是分开的：**出红睁大眼（震惊）· 出蓝闭着眼 · 出金和出紫半睁**。
- **他自己录的无水印视频**（`录制_2026_09_06_22_54_05_711.mp4`，28.5 秒 608×1000 30fps，同一段演了两遍）。

## 流程（2026-09-07 定版）

```
灰黑星星（蒙一层半透明的霜，呼吸 + 星尘，提示「擦一擦」）—— 此时**没有任何品质色**
   → 手指擦：擦开只是把霜抹掉，露出的还是同一张中性图
   → 擦到六成（或 3.5 秒没人擦）→ 直接开播短片，**没有白闪**
   → 短片：手心光晕**一亮就是这一抽的品质色** → 蓄力 5.31 秒 → 白光爆闪 0.25 秒 → 揭晓（越稀有越长）
   → 片尾 0.45 秒淡入结算卡底色 → 换成结算卡（两边同色，看不出接缝）
```

## 2026-09-07 大改：老板连退三次，每次的根因

**第一次**：「动画怎么做这么短，很多部分其实是不管出什么品质都是通用的？为什么没有这种通用的呀。
最后面显示结果的时候就突然戛然而止，像被中途掐断。」
→ **根因**：我只截了原片里「揭晓」那 0.6 秒，把 **0–6.5 秒的通用蓄力整段扔了**（28.5 秒素材只用了 2.4 秒）。
结尾是硬切，而且原片**音轨是数字静音**（实测 RMS −128dB），没声音本身就会让人觉得"没播完"。

**第二次**：「出蓝出紫出金出红手上刚开始用的星星颜色都是黄色，而且擦拭的时候没有那个闭着眼睛拿着黑星星的交互了。」
→ **根因**：通用段是从第 **2.40 秒**截的，正好跳过开头「闭眼抱黑星星」那一段，直接从手心已经亮起**暖金色**光的地方接进来。
所以擦完看到的黑星星跟视频第一帧对不上，四档开头也全是黄的。

**第三次**：「这个光晕不能是白色的，要出蓝就是蓝色光晕，要出红就是红色光晕。」
→ 我第二次修过头了：为了"通用段不剧透品质"把光晕压成白银色。**老板要的是相反的** ——
光晕提前定色、先给期待感（原神也是这个路子）。

**第四次（定版）**：「擦拭之前颜色和光晕不能变，擦拭完立马变。刚开始得得得得得很急促的背景音乐放缓一点。」
→ 视频起点再挪到**手心刚要亮的那一帧**，擦完立刻见光，中间不留空档；碎星音第一秒从 3 颗降到 2 颗。

一句话教训：**「通用」不等于「无色」**。通用的是那段**表演**（谁都要看蓄力），不是那段**颜色**。

## 四条短片是怎么剪的

每条 = **通用蓄力段 + 该品质的揭晓段**，接缝用原片自带的白光爆闪（xfade 0.25s 正好落在最白那一帧）。
通用段统一取 **1.06 → 6.62 秒**；`hue=h=<角度>:s=<饱和>` 只旋转色相 —— 原片除了那团暖光其余都是无彩色，
**色相旋转对无彩色像素不起作用**，所以只有光晕和发冠跟着变色，背景和人物本身一点没动
（试过 `colorbalance` / `colorchannelmixer`，那两个会把整张图染色，不能用）。

| 档 | 揭晓段（原片） | 色相 | 饱和 | 成片时长 |
|---|---|---|---|---|
| red | 6.62 → 8.58 | −30° | 1.5 | **7.30s** |
| gold | 8.60 → 10.52 | 0°（本来就是金的） | 1.3 | **7.27s** |
| purple | 11.63 → 13.15 | +235° | 1.5 | **6.87s** |
| blue | 10.53 → 11.62 | +180° | 1.5 | **6.43s** |

**越稀有揭晓越长**（蓝 1.09s → 红 1.96s），蓄力段四档一样长。
片尾统一 `fade=t=out:d=0.45:color=0x0B0D12`，且**提前 0.15 秒结束**让它真的走到底
（不提前的话末帧停在 #19 左右，换卡时能看出跳变；现在末帧 #0B0C13）。
成片共 3.3MB（原来 585KB）——素材大了 2.7MB，换的是老板点名要的完整度。

⚠️ **原片 0.25–0.50 秒有录屏时的 ▶ 播放按钮**叠在画面上，所以起点必须躲开它。

## 声音是我们自己合成的

原片音轨是**数字静音**。`design/music/make_gacha_sfx.py`（numpy，没有采样包，跟音游那套同源）：
蓄力 = 慢慢打开的气声 + 越来越密的碎星铃音；爆闪 = 一记亮铃 + 短气流；揭晓 = 按品质给动机
（蓝 2 音 → 红 和弦 + 低频涌），音阶用 A 大调五声。
⚠️ **尾巴必须自己衰减干净**：末尾还有声音的话，画面切走那一刻会被听成「咔」的一声断。
⚠️ **开头必须疏**：密度是这段的紧张感来源，起手就密等于一上来把话说完。

## 三条硬约束

1. ~~颜色在落定之前就说话~~ → **改了**：擦的过程里**一点品质色都不能有**（老板 2026-09-07）。
   颜色第一次出现是在短片开播那一帧。悬念从"擦的过程"挪到了"擦完那一下"。
2. **落定那一帧干净**（STYLE.md）：短片自己收尾，不留粒子。
3. **动画纯粹是表现层**（cc-logto_yxi）：结果在 `POST /api/wish/draw` 返回那一刻就落库了。
   所以**擦不擦、擦没擦完、短片放没放完，东西都已经是玩家的** ——
   不在动画中途重发请求，不把"擦完"当领取条件；中途退出/杀进程/断网，收藏页里都在。

## 技术要点

- **覆盖层必须走 Dialog**：直接摆一个 `fillMaxSize` 的 Box 会被页面内容盖住（Compose 同级后画的在上面）。
- ~~先闪 0.18 秒再挂播放器~~ → **去掉了**。短片第 1 帧就是擦完看到的那张（同一段视频差 0.06 秒），
  没有接缝要遮；延迟挂载还会让「擦完立刻亮」变成「擦完等一下才亮」，正是被退回的毛病。
- **片尾的交叉淡入烤进视频里**，不在 App 里叠两层 Dialog：视频淡到结算卡底色、整屏底色也在
  `drawBehind` 里跟着淡（`lerp(Paper, Stage, tail)`），换卡那一刻两边同色。**只淡中间那块视频不行**——
  四周那一圈浅灰会"啪"地变黑。
- 播放器用 **TextureView + MediaPlayer**，不引第三方；`MediaPlayer.create` 可能返回 null、`start()` 可能抛，
  失败就当播完，**绝不卡住出货**。Surface 要自己 release（`MediaPlayer.release()` 不管它）。
- **舞台比例必须是短片的真实比例 608:1000**：TextureView 是**拉伸填充**的，比例不对视频就被压扁。
- 擦拭用 **12×12 的格子**记覆盖率，不用路径：省内存、好算比例、天然有擦开的形状。
  ⚠️ **霜必须半透明**（FROST=0.72）：不透明的话擦之前是一片空白灰，老板要的是"擦拭的前面是灰黑星星"。
- 舞台底色 = **短片自己的底色 #E3E3E3**（不再是 #E1DAD7），擦完那张就是短片第 1 帧。
