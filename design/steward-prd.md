# PRD · 云曦小管家（v0 调研稿，2026-09-06，待老板拍板）

> 老板要的：「我的」和侧边栏加一个云曦入口，点进去是备忘录、提醒/闹钟、天气等方便的小服务，Q 版云曦像 Live2D 那样可交互。
> 本稿 = 三个子代理的发散（角色动效 / 服务与 API / 产品交互）+ 我对着真素材做的验证，收敛成一份可拍板的方案。素材已取回：`design/steward-art/`。

## 1. 一句话定位

**云曦小管家是一个「带人格的服务面板」**：用云曦的形象和口吻把一组高频小功能收在一页，让她从抽卡立绘变成日常陪伴。
**不是**聊天机器人（不接自由输入、不假装是 Claude）、**不是**通知轰炸器（推送默认全关、逐项开）、**不是**第二个看板（不重复会话状态）。

## 2. 素材现实（决定了动效方案）

- 4 张 Q 版云曦，1254×1254，**RGB 无透明通道，白底，角色本身也是白/奶白色**，风格统一，同一构图比例：
  ① 挥手打招呼 ② 双手捧云 ③ 举月牙杖悬浮 ④ 抱星星枕坐云上。正好对应 **问候 / 待机 / 办事 / 深夜** 四个状态。
- **没有分层**（眼、嘴、头、身不是独立图层）→ 真 Live2D（Cubism）和 Rive 都需要先做骨骼绑定，2–4 周 + 授权 / 月费，v1 排除；
  程序化切层不现实（白角色在白底上，头发 / 云冠边界软，切出来会露缝）。
- **抠底试过两种**（`steward-art/*_preview_*.png`）：
  - 从四边洪水填充「近白」：**失败**，脸 / 头发 / 云被挖穿（角色的白和背景的白连着）。
  - 不抠、四边径向渐隐：**浅色主题下天衣无缝**；深色下是一朵发光的白云托着她（可接受，但不如真抠图）。
  - **rembg 的动漫抠图模型（isnet-anime）：成功**，头发丝、云边、半透明纱都保住了，深色底上干净（`*_rembg_preview_dark.png`）。
    一张 74 秒，离线跑一次、四张带 alpha 的图打进 APK 即可。**抠底问题已解，不用老板重新出图。**

## 3. 角色动效方案（推荐：整图物理 + 姿势切换，零新依赖）

| 效果 | 做法 |
|---|---|
| 姿势切换 | 4 张图对应 4 个状态，`AnimatedContent` 交叉淡入淡出 |
| 呼吸 | 整体 scaleY 0.985→1.015 循环，锚点在脚底（悬浮姿势加正弦上下浮动） |
| 看向手指 | 手指靠近 → 整体微旋转 ±3° + 微平移（视差），弹簧回位 |
| 戳一下 | 整体弹跳（spring 过冲）→ 说一句 → 回待机；连戳第三下换台词 |
| 拖拽 | 跟手 + 松手弹回（`spring` 600ms） |
| 时段 | 22:00–06:00 切「抱星星」，呼吸变慢；戳一下短暂醒来再睡 |
| 办事 | 服务执行时切「举杖」2 秒（备忘存好了 / 提醒设好了 / 天气取到了） |
| 减弱动效 | 循环全停、姿势切换保留、台词照出（STYLE.md §2.4） |

**上限要说清**：这是「会呼吸、会弹跳、会换姿势、戳了有反应的立牌」，没有眨眼、嘴型、瞳孔追踪。
**投入产出比最高的一步**：请老板再出 **3 张同姿势（捧云）不同表情**——闭眼、笑、惊讶（同 seed 微调 prompt 即可）。
有了闭眼图就能做随机眨眼（3–6 秒一次、60ms 交叉淡入），有笑 / 惊讶就能做被戳 / 被拖的情绪反应，效果从立牌跳到「有情绪的角色」，只多半天工。

工期：抠底半天 + 交互 1.5–2 天 ≈ **2–3 天**；APK +1–2 MB；零新依赖。升级路径：用户喜欢再考虑 Rive（可导入 PNG，有状态机）。

## 4. 服务（v1 六项，全部纯客户端，不动服务端）

| 服务 | 数据 / 机制 | 说明 |
|---|---|---|
| **备忘录** | 本机 prefs 存 JSON（≤200 条、单条 ≤5000 字） | 纯本地、不上传（隐私）。列表 + 编辑，长按删。以后要同步再说 |
| **提醒 / 闹钟** | `AlarmManager.setAlarmClock`（穿透 Doze、OEM 最难杀、状态栏有闹钟图标）+ `USE_EXACT_ALARM`（闹钟类免申请）+ 重启恢复（已有 BootReceiver） | 通知渠道「云曦提醒你」，可选铃声 / 震动；支持每天 / 每周重复；≤50 条 |
| **天气** | **Open-Meteo**（免 key、10000 次/天、CC BY 署名、含 AQI、地理编码支持中文城市）；备选和风天气免费档 | **手动选城市、不申请定位权限**（一个 SSH 控制台要定位显得可疑）；缓存 30 分钟；取不到就说取不到 |
| **签到状态** | 现有 `/api/checkin` | 「今天还没签」一句 + 跳签到 |
| **深渊倒计时** | 现有 `/api/abyss` | 距重置 N 天 · 本期 N/36 星 · 新一期未打红点 |
| **未读邮件** | 现有 `/api/me` | 数字 + 跳邮件 |

v2 候选（按价值排）：签到 / 深渊重置 **推送**提醒（默认关、每天最多一次）· 每日简报（早间一条：天气 + 签没签 + 未读信 + 在跑的会话数）· 世界时钟（复用 `Tz.kt`）· 倒计时 / 计时器 · 「帮你问你的 Claude」（跳到用户选的会话把一句话发过去，云曦自己永远不假装是 AI）。
不做：汇率、自由问答、任何积分 / 打卡义务。

## 5. 页面与交互

- **入口**：「我的」四宫格扩成五格，第一格「小管家」（Q 版头像剪影）；侧边栏功能区第一行「云曦」，尾部带一句当前时段问候。两处进同一页。
- **布局**：上 40% 是云曦互动区（呼吸光晕复用输入框那套 2.6 秒参数）；下 60% 是服务卡列表（图标 + 标题 + 一行摘要 + 箭头）。点卡展开内容；云曦说对应台词、头顶冒小动效（备忘 = 一朵云、天气 = 太阳 / 雨滴）。
- **失败态**：卡片摘要直接写原因（网络不通 / 登录过期 / 没选城市），不留空白、不静默。
- **首次进入**：从云雾里浮现（0.6 秒）+ 一句欢迎；之后直接给面板，不重复欢迎。
- **她穿戴用户当前装备**：头像框（王棋彩框）直接套在 Q 版头上，换装即时反映——不加任何新经济。
- **深色主题**：背景改深蓝夜空，立绘不变；**中英文**：全部台词过 `t()`，英文保持空灵语气、不硬翻古风。

### 台词样例（她的口吻：短、空灵、不油）
- 早「晨雾还没散呢……今天也要加油呀。」· 午「正午的光太亮了，我替你挡一挡。」· 晚「星星快出来了，今天辛苦了。」· 深夜「这么晚还在呀……云曦陪你。」
- 戳一下「嗯？」· 连戳「别戳啦，发间的云要散了……」· 长按「你的手指好暖。」
- 闲置「又有一颗星熄灭了……不过没关系，它的梦我收好了。」
- 备忘空态「备忘录空空的，写点什么给明天的自己吧。」· 签到「该签到啦——今天的曦光还没拿呢。」
- 提醒到时「提醒你：「%s」。」· 天气「外面……%s，%s°。」· 天气失败「没取到天气……可能是网不太好。」

## 6. 权限 / 隐私

新增只有 `USE_EXACT_ALARM`（侧载不需要 Play 审核）。**不申请定位**（手动选城市）。备忘录、提醒内容纯本地；天气请求只带经纬度不带身份。推送默认全关。

## 7. 要老板拍的决定

1. **表情图**：能否再出 3 张同姿势不同表情（闭眼 / 笑 / 惊讶）？这是效果的最大杠杆。
2. ~~底色~~ 抠底已用模型解决，不需要重新出图（以后再出图若能给透明底当然更好）。
3. ~~天气定位~~ **老板 2026-09-06 拍板：用手机定位**（试了搜「长沙」搜到别省镇村后）。实现：只要 `ACCESS_COARSE_LOCATION`，「用当前位置」按钮 → 拿一次粗略位置反查成城市 → 只存城市不存坐标；手动搜城市保留为后路，搜索改成补「X市」+ 按人口排序（pilot）。
4. **v1 服务集**：上面六项照做？推送提醒放 v2 且默认关？
5. **名字**：宫格叫「小管家」还是直接叫「云曦」？（侧栏建议叫「云曦」）

## 8. 工期

客户端约 **4–5 天**：角色 2–3 天 + 备忘录 / 提醒 1 天 + 天气 / 三张状态卡 1 天 + 审查 / Mac E2E 半天。服务端 v1 **不需要改动**。

## 9. 验收（v1）
1. 「我的」与侧边栏两处入口进同一页；首次进入有浮现 + 欢迎，之后不重复。
2. 云曦有呼吸；点、连点、长按、拖拽各有不同反应与台词；22 点后切深夜姿势。
3. 六张卡全显示；签到 / 深渊 / 邮件读到真数据；取不到时写原因。
4. 备忘录增删改，退出再进不丢。
5. 提醒到点弹通知（云曦渠道）、重启后仍会响；重复提醒能续。
6. 天气：选城市后一句话天气 + 30 分钟缓存；没选城市 / 网络失败各有明确提示。
7. 减弱动效：循环全停、台词照出；深色主题对比度达标；英文环境全部英文。
8. 她头上戴着用户当前装备的头像框。
